# v2 suggestions — neetu-portfolio

Ideas raised during design (10 Oct 2026) but not part of the first version. Not on the roadmap; revisit after launch.

| Idea | What it would do | Notes |
|---|---|---|
| Reading time per work | Show "लगभग 8 मिनट" on work rows and work pages | Needs a word count or reading-time field per work; story text isn't hosted here, so it would be entered by hand in admin. |
| Sticky filter / count bar on phone | Keep "और फ़िल्टर" and the result count visible while scrolling long catalog lists | Must not cover content or shrink the reading area much on small phones. |
| "क्या आप यह खोज रहे थे?" | On an empty search, suggest close title matches (e.g. a typo or a different spelling) | Could use simple similarity on titles; useful with voice search, which often mishears. |
| Site-wide text-size control | A visible "अक्षर बड़े करें" control that increases all text | Browser zoom and the browser's text-size setting already work (text sizes are in `rem`); this would make it discoverable for older readers. Store the choice in `localStorage`. |
